# Code of Conduct

Sentinel is intended to be a professional, security-focused open-source project.

## Standards

Expected behavior:

- Be respectful and constructive.
- Discuss technical tradeoffs with evidence.
- Keep security reports responsible and private until coordinated disclosure is appropriate.
- Avoid personal attacks, harassment, or discriminatory language.

Unacceptable behavior:

- Publishing exploit details for unresolved vulnerabilities without coordination.
- Harassing contributors or users.
- Sharing private data, secrets, or credentials.
- Using project spaces for spam or unrelated promotion.

## Enforcement

Maintainers may remove comments, close issues, block users, or restrict participation when behavior harms the project or its contributors.
